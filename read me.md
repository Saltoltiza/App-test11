# Habit Tracker & Personal Improvement App

A comprehensive mobile application for tracking habits, setting reminders, and monitoring personal improvement progress.

## Features

- **Habit Management**: Create, edit, and track daily habits with categories
- **Progress Tracking**: Visual charts and statistics for habit completion
- **Reminders**: Customizable notifications and reminders
- **Personal Profile**: User stats and achievements
- **Data Persistence**: Local storage with AsyncStorage
- **Motivational Quotes**: Daily inspirational messages
